# Adwaith VK — Safety Officer Portfolio

This version includes the two supplied professional images:
- `assets/adwaith-safety-site.jpg` — main Safety Officer hero image
- `assets/adwaith-office.jpg` — About section image

## Personalise it
1. Replace the placeholder email, phone and LinkedIn URL in `index.html`.
2. Add your CV as `assets/ADWAITH_VK_CV.pdf`.
3. Replace the sample certification/project cards with your actual certificates and projects.

Open `index.html` in a browser to preview the site.

## Publish
The folder can be published with GitHub Pages, Netlify, or Vercel.
